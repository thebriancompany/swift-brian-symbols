# 심볼 형태와 이름 규칙

기본형은 외곽선형(outline)을 우선하고, 채움형은 `.fill` 접미사로 구분한다. 색상 모드와 크기는 에셋 이름에 넣지 않는다. 아래 규칙은 Brian Symbols의 프로젝트 규칙이며 Apple 이름 전체의 문법을 재현하는 규격은 아니다.

## 외곽선형과 채움형 제작

SF Symbols는 outline, fill, slash, enclosed 등 형태 변형을 제공한다. 외곽선형과 채움형은 같은 의미를 유지하면서 시각적 강조를 달리하는 데 사용할 수 있다. [Apple의 형태 변형 안내](https://developer.apple.com/design/human-interface-guidelines/sf-symbols)

- 기본형과 채움형이 모두 유용한 심볼은 한 쌍으로 제작한다.
- 화살표, 더하기처럼 채움형의 구분이 불필요한 형태는 기본형만 제공할 수 있다. 차이가 없는 `.fill` 에셋을 복제하지 않는다.
- 외곽선형도 배포 시에는 닫힌 면으로 제작한다. outline은 시각적 형태를 뜻하며 SVG stroke를 그대로 남긴다는 뜻이 아니다.
- 채움형은 내부 공간과 세부 표현을 별도로 조정한다. 외곽선형의 색상 모드만 변경해서 만들 수 없다.
- 두 형태는 같은 정사각형 영역, 중심과 색상 역할을 공유한다. 채움형의 면적이 커져 지나치게 무거워 보이면 시각적으로 보정한다.

채움형을 선택 상태에 활용할 수 있지만 `.fill` 자체가 선택 상태를 뜻하지는 않는다. 상태에 따른 형태 선택은 사용 화면의 책임이다.

## 에셋 이름

기본 형식은 `brian.<대상>[.<방향>][.slash][.<컨테이너>][.fill]`이다. 대괄호는 선택 항목이며 실제 이름에는 넣지 않는다. 컨테이너는 `circle` 또는 `square` 중 하나를 사용한다.

방향은 대상 바로 뒤에 둔다. 예를 들어 `brian.arrow.right`는 대상이 `arrow`, 방향이 `right`이고, `brian.arrow.right.circle.fill`은 오른쪽 화살표를 채워진 원으로 둘러싼 형태다. 방향이 없는 대상은 해당 항목을 생략한다. `magnifyingglass` 같은 합성 명사는 하나의 대상 이름으로 쓰며 단어마다 점으로 나누지 않는다.

| 규칙 | 예시 |
|---|---|
| 접두사는 `brian.` | `brian.flower` |
| 소문자 영문을 사용하고 의미 단위를 점으로 구분 | `brian.arrow.right` |
| 화면 위치보다 대상이나 동작을 이름으로 사용 | `brian.house`, `brian.magnifyingglass` |
| 기본형에 `.line` 또는 `.outline`을 붙이지 않음 | `brian.heart` |
| 채움형은 `.fill`로 끝남 | `brian.heart.fill` |
| 색상, 크기, 굵기와 버전 번호는 넣지 않음 | `brian.flower`에 표시 설정을 적용 |

같은 대상을 `home`과 `house`처럼 서로 다른 이름으로 중복 등록하지 않는다. 새 이름을 추가하기 전에 기존 에셋 목록을 확인한다. Swift 공개 API의 식별자 변환 규칙은 API 구현 때 정하며, 에셋 이름과 구분한다.

## 형태 수식어

초기에는 기본형과 `.fill`을 우선 제공한다. 실제 필요한 변형만 추가한다.

| 수식어 | 의미 | 예시 |
|---|---|---|
| `slash` | 대상에 사선을 추가한 형태 | `brian.bell.slash` |
| `circle` | 원으로 둘러싼 형태 | `brian.heart.circle` |
| `square` | 사각형으로 둘러싼 형태 | `brian.heart.square` |
| `fill` | 채워진 형태 | `brian.heart.fill` |

복합 수식어는 에셋 이름 형식의 순서를 따른다. 예를 들어 `brian.bell.slash.circle.fill`은 사선이 있는 종을 채워진 원으로 둘러싼 형태다. 컨테이너 뒤의 `.fill`은 컨테이너의 채움을 뜻한다. 예를 들어 `brian.heart.circle.fill`은 채워진 원 안에 하트가 있는 형태이며, 하트 자체의 채움까지 약속하지 않는다. 초기에는 내부 대상과 컨테이너의 채움을 독립적으로 조합하는 이름을 추가하지 않는다. 필요해지면 구분 규칙을 먼저 확장한다.

`square`는 눈에 보이는 사각형 컨테이너를 뜻한다. 모든 심볼에 적용하는 정사각형 레이아웃 영역을 뜻하지 않으므로, 크기를 통일한다는 이유로 모든 이름에 붙이지 않는다.

## 형태와 색상 모드의 조합

| 요청 | 사용할 에셋 | 표시 설정 |
|---|---|---|
| 꽃 기본형의 기본 컬러 | `brian.flower` | Multicolor |
| 꽃 채움형의 기본 컬러 | `brian.flower.fill` | Multicolor |
| 꽃 채움형의 보라색 단색 | `brian.flower.fill` | Monochrome + 보라 |
| 꽃 기본형의 사용자 팔레트 | `brian.flower` | Palette + 세 그룹 색상 |

`brian.flower.line`, `brian.flower.multicolor`, `brian.flower.black`, `brian.flower.24`처럼 형태·렌더링·크기를 혼합한 이름은 만들지 않는다.

커스텀 에셋의 이름에 `.fill`을 붙였다는 이유만으로 시스템 심볼처럼 자동 전환이나 형태 생성이 보장되지는 않는다. 기본형과 채움형을 각각 제작하고 필요한 에셋을 명시적으로 선택한다. 라이브러리의 자동 선택 기능은 추후 별도 구현과 검증이 필요하다.
